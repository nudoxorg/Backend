# Retained display cache: source proof and pending gates

This patch extends NXSNAP schema 4 with closed, bounded display projections. It reuses the existing table/section SHA-256 checks and total 8 MiB payload budget; it does not duplicate the owner IR, embeddings, manifests, selected frontier or CAS. The existing owner CAS already serves immutable local ranges before its exact remote fallback. The GUI has no independent validated CAS-read capability and creates none here.

New capture coverage is Tree, Find/FindHome, Compare, World, exact Cargo source and a successfully read Cargo README. Missing README, source inventory and operation/graph continuations are not fabricated into cached empty results. Existing Symbol/Source/Package/Orbit SeedEntry coverage remains. Display rows have no semantic destinations or callbacks. Display source/Markdown bodies retain plain bytes, never a current source/editor lease. A projection always reports `served() == false`.

Display identity contains the full persisted typed destination, including query limit, ordered comparison identities, full package origin/release/source target/line/README origin, and exact native project identity where the route names one. The table additionally binds the absolute private workspace data namespace. Historical observation stores producer epoch and cursor/root bytes without reconstructing a current VersionedRoot. Cargo content is checked against its digest and exact request binding/source target; Tree requires a producer binding matching its requested native root. Only an already requested route selects a section. Cache data never creates navigation intent or adopts an owner root.

Capture selects immutable Arcs cheaply from completed, nonseeded, nonrevoked, non-inflight current reads. Row traversal and bounded preparation happen on the background executor; launch reading/decoding stays in the existing snapshot thread. Installation of a prepared display rechecks current owner serving, exact route, cursor and epoch after the worker returns. Private platform IO opens the bounded cache and atomically writes it and observed `.bad` bytes. Refusing a nonprivate/link/hardlink file happens before observing its bytes.

The prior `the_first_frame_is_the_page_the_window_was_left_on_and_its_owner_confirms_it` test explicitly demanded promotion of cached documentation by equal root/build without any fresh symbol/package read. That expectation enforced an unsafe authority shortcut. Its replacement latches fresh owner reads, proves the equal-root seed remains unserved and semantic leases cannot be captured, then proves an equal fresh answer preserves the content stamp while granting current admission. A captured fresh lease is denied immediately after owner revocation. The keeper no longer calls root/build-only confirmation for any cached family; equal fresh PageStore landing still supplies the legitimate quiet promotion.

Source tests cover exact query/limit and namespace cold misses; recomputed hashes with mismatched observation; unknown capability fields; row/text/cursor bounds; Cargo target/line/binding/revision/digest mismatch; private-mode/symlink/hardlink refusal; seeded/inflight/wrong-root/revoked capture refusal; exact Cargo payload mismatch; and capture row preallocation bounds. Corruption fixtures use actual private writes so their refusal tests reach the decoder rather than merely failing file permissions. Existing cache tests remain otherwise intact.

Limits: this is one last-route snapshot, not an unbounded cache or source inventory. New projections are saved at rest; quitting before worker preparation may omit that projection. The existing bounded synchronous quit writer remains for already prepared displays and legacy SeedEntry payloads. Plain projections do not preserve interactive diagrams, alignment inspectors, continuations, actions, rich source indexes or unavailable CAS references. Native Reader integration belongs to the separately composed retained-content patch.

Validation in this isolated worktree is source parsing with rustfmt and whitespace checks only. Cargo compilation, unit/native tests, cold restart, native paint/AccessKit, responsiveness and the full width/text/theme matrix are pending root composition and an explicit gate. Source proof is not a runtime pass.
