## Architecture contracts and structural repairs

### Local state does not need an index permission

The shelf, project addresses, settings, inbox, saved navigation, and onboarding are local application state. A failed or starting owner cannot replace these surfaces with a remote read failure. Selecting a saved local address is allowed offline; executing a content-dependent action requires the corresponding current producer observation.

`RouteDependencies` derives a closed `ContentAdmission`: ready, pending, or a terminal failure attached to the exact required key. ### Startup discovery is a retryable producer

The application constructs its UI, actor, and read lanes before host discovery succeeds. They share one immutable `Binding` installed by the actual host discovery producer before owner Ready. ## Testing method and integration sequence

Dan Luu's recent [agentic testing experiments](https://danluu.com/agentic-testing/) show that naming a sophisticated technique or adding many small tests does not reliably improve agent correctness; structured valid inputs can expose bugs that random rejection inputs miss. His [testing essay](https://danluu.com/testing/) emphasizes useful generators and testing throughput, and [agentic coding notes](https://danluu.com/ai-coding/) stress inspecting data and solving problems systematically. Our application-specific consequence is to write independent behavioral oracles and realistic failure schedules, not count assertions or announce a framework as proof.

For this code, independent oracles include unchanged source hashes; full reopen against selected immutable metadata; identical package/profile/origin answers across GUI/CLI/MCP; exact durable keyed request evidence after each crash boundary; source bytes reconstructed losslessly across page boundaries; and native pixels/AX compared under the same actual state. Valid generated schedules vary publish/restart/replay order, cancellation timing, late old-owner replies, root replacement, link occurrence, UTF-8/page boundaries and final focus changes. Negative mutations must be shown to fail the appropriate oracle: dropping request-key binding, accepting invocation recipe as source recipe, promoting cache from root equality, deleting ACK before receipt, or allowing a later input to satisfy an earlier capture. Most new composed tests remain unrun; this paragraph defines required experiments rather than claiming completion.

The next integration sequence is deliberately concrete:

1. Preserve the compiled25e69 artifact/source and finish fresh startup, first/second Add, actual source/README/navigation/Settings and cold-restart observations. Attach each failing native path to the shared contract and exact binary.
