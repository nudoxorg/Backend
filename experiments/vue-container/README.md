# Native Vue container proof

This isolated experiment calls Verter's native Vue SFC tokenizer and Syntax parser on the original UTF-8 host. It snapshots finalized parser nodes as events arrive because the final descriptor replaces duplicate script/template nodes. Block, attribute and embedded content positions refer directly to host bytes; `Block::host_range` checks the child range before translating it. The copied `UnicodeCard.vue` is the synthetic research fixture, including its BOM and CRLF bytes.

This is not a product frontend or an admission to the index. External `src` attributes are captured but are not resolved; embedded scripts, templates, styles, Sass, CSS Modules and Vue scope transforms are not analyzed here. Neither a parsed block nor an empty diagnostics list establishes embedded language or Vue semantic completeness. Verter's diagnostics are retained verbatim. Duplicate scripts are diagnosed by Verter; duplicate-template conformance and other unsupported or erroneous cases need independent verification before any publication. No generated code or concatenated source establishes source correspondence.

`verter_core` is pinned to 0.0.1-beta.1 with default features disabled. That upstream crate unconditionally depends on OXC and LightningCSS even though this experiment uses neither as the embedded-language semantic producer. Its Cargo.lock pins transitive dependencies for this proof. The experiment does not designate either as the product CSS authority. It is deliberately outside the workspace while its parser behavior, resource cost, distribution and product integration are evaluated.
