## TESTING.md mapping

- Universal exact negative space, deterministic sequences, conservation after each step,
  representation, idempotence/conflict, cancellation prefixes, actual public types, exact iterator
  cardinality, source-preserving conversion, and abstraction stress map to the first eleven rows.
- Operation/runtime cursor fusion, unique ownership, capacity product, simultaneous producer/consumer
  behavior, workflow transition product, and deterministic wake/cancellation map to terminal, replay,
  cancellation, and pressure rows.
- End-to-end constant-body sensitivity, stale substitution, local/degraded/newly available behavior,
  exact provenance, and no empty success map to semantic owner, local-first result, process, MCP, and
  GPUI rows.
- Binary frame, root builder, store collision, durable file crash, Loom, Miri, and authenticated
  range clauses are excluded from Wave C.7 only when the application service does not alter or
  reimplement those owners. Any later direct use reopens the matching clause.
