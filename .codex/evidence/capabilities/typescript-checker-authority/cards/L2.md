## The 14 feature classes (mandate lattice + render law)

Each class = one TypeScript source (inline const bytes), one public
compile_ir, and exact display-text assertions via the compiler-ir render
displays:

1. recursive type (`interface Node { next: Node | null }`)
2. nominal (interface + class with members)
3. generic application (`Holder<number>`, two params `Pair<K, V>`)
4. conditional type (`type Cond<T> = T extends string ? "s" : "n"` —
   declared plane renders the honest TypeReason record; assert the exact
   unknown-with-reason rendering)
5. mapped type (`type Readonlyify<T> = { readonly [K in keyof T]: T[K] }`)
6. template-literal type (`type Greet = \`hi ${string}\``)
7. literal types (string/number/bigint/boolean literals in unions)
8. self-nominal (`class Box { self(): this }`)
9. inference + widening (`let x = 7;` / `let w: number = 0; w = "t"` narrowing)
10. `this` in function result and expression position
11. narrowing site rows (the golden `widened` case: assignment-site computed row)
12. JSDoc (`/** ... */` with `@param`/`@returns` on a function; DocsDisplay
    exact text + link targets)
13. overloads (two `declare function g` + call sites; SignatureDisplay per
    overload fact; oracle-confidence call rendering)
14. extension facts (generic declaration's TypeScript extension plane row:
    type_parameters count + declared/computed cells via
