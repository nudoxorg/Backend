## Public terminal

Every projected Go constant fact carries its exact oracle constant facts
on the landed 44-byte `GoFacts` extension row (W7 wire):

- `constant_value`: atom list holding exactly one atom — the image
  declaration's exact `value` bytes (`constant.Value.ExactString`),
  interned in the shared atom arena; the empty pooled list for
  declarations that carry no value.
- `constant_group`: the image declaration's `const_group` i64 verbatim.
- `constant_flags`: bit 0 set iff the image declaration's `iota` is true;
  all other bits zero.

Non-constant declarations keep the zero cells today's constructors
already emit (`constant_value` = empty list coordinate, group 0,
flags 0).

## Required falsifiers (tests in `mod tests`, each naming its law)

1. Const with value + group + iota: image fixture declaring a constant
   whose row carries a non-empty `value` atom, `const_group != 0`, and
   `iota = true`. Decode the fact's extension row through `go_extension`
   and the pooled atom list; assert the exact value bytes, exact group,
   exact flags. `go_extension` currently decodes rows at the stale
   28-byte width; fix it to the landed 44-byte width — this helper fix
   is part of this card.
2. Const outside any group: value present, group == 0, iota flag clear.
3. Non-constant (type and func) facts: empty value list, group 0,
   flags 0 — mixed with facts 1-2 in one fragment to prove per-entity
   routing.
4. Flip `constant_values_stay_image_only_without_changing_the_projection`:
   the M6 fork resolution retired the image-only law for constants.
   Replace it with the projected law (test 1-3 cover this); do not
   delete the coverage silently — the replacement must still prove the
   projection changes when the image value changes (mutate the value
   bytes, assert the fragment changes).
5. Capacity terminal: `capacity_beyond_the_lane_rejects_exactly` flips
   from the folded `Lowering(NoSupportedDeclaration)` to the exact
   `GoCollectError::Rejected(FactRejection { fact: MAX_EMISSION_FACTS,
   cause: FactFault::Capacity, .. })` (observed live:
   `fact: 1024, name_len: 5, cause: Capacity`). Keep asserting the exact
   rejected ordinal and cause.
