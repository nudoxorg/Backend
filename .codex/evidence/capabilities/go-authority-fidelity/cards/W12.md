## Required go_support additions

1. Module-path escaping for the proxy protocol (uppercase letters encode
   as `!` + lowercase — verified live: `github.com/!burnt!sushi/toml`
   serves BurntSushi/toml). Unit-test the escaper.
2. A `journey` entry point the corpus rows share (locate -> download ->
   digest verify -> unpack (+ pre-module go.mod synthesis) -> oracle
   image -> compile_ir -> compile -> publish -> reopen -> index ->
   gen-2 -> gen-1 revalidation), returning a typed per-row outcome:
   `Complete { entities, generation }` or `CapacityTerminal { entities,
   capacity }` (the shared 256 bound). Any other terminal is the row's
   failure.
3. Per-row timing capture: wall from PURL parse to final revalidation,
   plus the oracle-image duration; printed as one
   machine-parseable line per module.

  go-homedir, httprouter, xxhash, quote-style tiny rows are expected

  ulid, xxh3, highwayhash, chi, mux, zerolog, go-spew, BurntSushi/toml
  may land `Complete` OR the typed `CapacityTerminal` — pin whichever
  you OBSERVE after one run (the expectation becomes the regression
  pin), and record the observed entity count.
- Source-truth review (the M9 heart): for EVERY row, assert at least
  four decoded symbols that you have verified against the downloaded
  sources (functions, types, and at least one method); where a symbol
  surprises you, correct against the source and record the correction.
  Also assert per row: the image binds the primary source digest; the
  fragment decodes; occurrences lane present; docs present for at
  least one documented declaration in at least the rows landing
  `Complete`.
- Assembly edges recorded: pkg/errors + go-homedir pre-module go.mod
  synthesis; BurntSushi case-escaped fetch; x/tools is the
  multi-module-repo row.

## Falsifiers (law-shaped, not happy-path)

1. Corrupt one downloaded zip byte in a diagnostic test: typed
   digest rejection, never a projection attempt.
2. One row re-run with a mutated expected symbol (absent from the
   module): typed failure naming the absent symbol.
3. The escaper unit tests: `BurntSushi` -> `!burnt!sushi`; lowercase
   passthrough; digits/dots untouched.
