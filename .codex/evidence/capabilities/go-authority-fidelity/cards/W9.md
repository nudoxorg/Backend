## Context (manager-verified facts; re-verify before relying on them)

The trunk landed three changes these tests never calibrated against:
schema-2 type-fact wire (computed segment), the 44-byte Go extension row,
and cause-retaining emission terminals (exact `FactRejection` operands
instead of the folded `NoSupportedDeclaration`).

1. GO DECODERS (7 red tests). `field_children` in lower/go.rs `mod tests`
   walks `view.type_fact_payload()` from offset 4 with one leading count.
   The schema-2 layout (see `compiler/ir/type_facts.rs::write_payload` /
   `validate_payload`) is: u32 declared_count, u32 computed_count at
   offsets 0/4; records start at offset 8; each record is owner u32,
   tag u8, payload0 u32, payload1 u32, text cell, text2 cell
   (presence byte 0/1, then u32 len + bytes), nominal
   (0 = none; 1 = local + u32; 2 = external + 32-byte identity + u32),
   children.start u32, children.length u32. After all records: u32
   child_count, then child entries (0 = local: u32 target; 1 = external:
   32-byte identity + u32; 2 = text: nothing), each followed by a name
   cell and a flags u8. The record-walk start offset 4 -> 8 is the
   concrete drift. Fix the ONE shared helper; the seven tests
   (primitives, slices_arrays, signatures, struct_fields,
   generic_named_roots, nested_named_references,
   recursive_pointer_field) must pass without weakening any assertion.
2. GO PRIMITIVES (independent one-line drift). The test helper
   `arch(signed)` computes `TypeWidth::Arch.to_cell() | signed`, but the
   landed encoding shifts the width cell above the signedness bit
   (`INTEGER_WIDTH_SHIFT`, see `SemanticTypeRecord` and the projection's
   `signed()` in `basic_leaf`): `(to_cell() << INTEGER_WIDTH_SHIFT) |
   signed`. Manager-verified live: row 0 actual p1 = 131073 vs expected
   65537.
3. JAVA capacity test: same cause-retention flip as go's — expect the
   exact capacity `FactRejection` (fact == the lane bound, exact cause)

   `capacity_beyond_the_lane_rejects_exactly` (keep the java test's own

4. CSHARP lane-bound test: fails `Admission(Write(OutputTooSmall {

   write-exactness; keep rejecting bound+1.
