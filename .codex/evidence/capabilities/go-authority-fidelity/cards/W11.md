## go_support module (typed, no silent fallbacks)

  for malformed input (model `python_support::Purl`).
- `locate`: `GET https://proxy.golang.org/<module>/@v/<version>.info`
  (JSON: Version, Time) and `<module>/@v/<version>.ziphash` when served
  (hex sha256 of the zip) for digest binding; if the proxy does not

  `.zip` sha256 recorded from a first fetch ONLY into the assertion,

- `unpack`: the module zip's internal layout is `<module>@<version>/...`
  — unpack under a fresh temp root; zip-slip defense (reject entries
  escaping the root); no silent skip of failures.
- `fresh_dir`: unique temp dir under the system temp path.

## The journey (one pinned module: `golang.org/x/sync@v0.10.0`)

1. Parse PURL, locate, download the zip, verify digest, unpack; primary
   source file `errgroup/errgroup.go` inside the unpacked module root.
2. Run `GoOracle::authority_image(primary, module_root)`; assert the
   image opens (`GoImage::open`) and binds the primary's exact sha256.
3. `compile_ir` with `SemanticAuthorityInput::Go`; assert decoded
   entities include the source-truth symbols of the loaded module
   packages: `errgroup` (`Group`, `Go`, `TryGo`, `Wait`, `SetLimit`,
   `WithContext`) and `singleflight` (`Group`, `Do`, `DoChan`,
   `Forget`) — exact-name matches against the real sources; if any
   name is genuinely absent from these pinned sources, correct the
   list against the fetched source and record the correction.
4. `compile` a fragment; `FragmentView::validate`; assert an occurrence
   lane exists.
5. Publish (DurablePublisher::create, publish_compiled, shutdown),
   reopen, open_published; build the index for generation 1 exactly
   along the python template's choreography and scratch sizing.
6. Generation 2: append a probe declaration to the primary source
   (e.g. `func GenTwoProbe() int { return 2 }`), re-run the oracle,
   re-compile, publish into the SAME journal (chained generation), and
   assert the publication generation advanced.
7. Reopen once more: BOTH generations' fragments reopen and validate;
   gen-1's facts still contain `Group` and do NOT contain
   `GenTwoProbe`; gen-2's facts contain both.
