## Dodge 1: silent test skips (brief law: typed-unavailable failure mode)

protocol.rs lines ~245, ~459, ~649 print "skipping Go oracle/authority-
image e2e: ... unavailable" and `return Ok(())` when the toolchain
cannot spawn — a broken oracle path masks as green (observed live at
the W13 freeze: the e2e tests passed as no-ops without
COMPILER_GO_COMPILER). The python lane fails typed (`MissingPython`).
Replace each skip with a typed failure that names the toolchain and
the variable (`COMPILER_GO_COMPILER`), matching the existing
`OracleError::ToolingUnavailable` shape — the tests must FAIL, not
skip, when the toolchain is absent.

## Dodge 2: oracle load errors are silently dropped on the authority path

`Output.Errors` carries package-load diagnostics; the oracle proceeds
best-effort, skipping packages whose types failed. The Rust side
decodes `errors` and never checks it, so a misassembled module yields
a certified image that silently misrepresents the module. Fix on the
PRODUCER boundary: `writeAuthorityImage` (the `--authority-image`
path only — the JSON transcript mode legitimately carries errors for
diagnostic consumers) must REFUSE to write an image when
`len(output.Errors) > 0`, exiting non-zero with a typed stderr
message that retains the first error line. The JSON mode keeps its
current behavior.
